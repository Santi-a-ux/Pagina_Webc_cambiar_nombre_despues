Talleres y encargos

Los grupos son de seis personas. El encargo de un instrumento tarda entre seis y doce semanas, según la cola del luthier.

Agenda del mes

Tiple, sábados 10:00

Ocho sesiones. Se parte de rasgueo y se llega a un bambuco sencillo. Incluye tiple de estudio durante la clase.

Cuatro llanero, sábados 14:00

Golpe, bordoneo y dos pasajes de joropo. Para quien ya tiene oído, aunque no haya tocado cuatro.

Encargo a medida

Se define escala, maderas y presupuesto con el luthier. No hay adelanto por el formulario: primero se responde el correo.

Inscripción o consulta

El envío no sale si falta un campo o si el correo está mal escrito. Los avisos aparecen debajo de cada campo.

Recibimos tus datos en esta página. En un proyecto con servidor, aquí saldría el correo al taller. Por ahora el formulario queda listo para conectar Formspree o la API de la Entrega 2.
